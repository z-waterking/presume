# 简历版本存档

> 每次对 `resume_final.md` 做重大修改前，将当前版本存档到此目录。

## 命名规范

```
{日期}_{版本号}_{范围}_{描述}.md
```

### 字段说明

| 字段 | 格式 | 示例 |
|------|------|------|
| 日期 | `YYYYMMDD` | `20260413` |
| 版本号 | `v2`, `v3`... | 从 v2 开始递增 (draft 是 v0, 当前 final 是 v1) |
| 范围 | 修改涉及的模块 | `agent` / `msm` / `alibaba` / `全量` / `custom` |
| 描述 | 本次修改核心 | `强化MCP经验` / `添加英文版` / `字节投递版` |

### 示例

```
20260413_v2_agent_强化MCP经验.md
20260415_v3_全量_添加英文版.md
20260420_v4_alibaba_重写推荐系统描述.md
20260501_v5_custom_字节投递版.md
```
